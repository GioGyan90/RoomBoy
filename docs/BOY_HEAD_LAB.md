# 少年头部建模实验

入口：`?view=head`。人体结构研究页和人物审阅工具栏均有链接。

## 范围

纯 JavaScript + Three.js 生成，无外部模型、头发、颈部、眼球。当前为静态通用少年造型，尚无用户确认的正侧设定图，不宣称精确临摹或已达到角色最终美术标准。

代码：`src/experiments/head/boyHead.js`（逻辑笼架、镜像、网格生成）、`headLab.js`（独立实验页）、`headLab.css`。

## 方法

继承 STRUCTURE_STUDY.md 的“比例→体块→必要布线”和多角度检查。头部使用解剖站位而非球体变形；面部半边控制网格和后脑截面共用太阳穴边，镜像时焊接中心线。鼻部和闭合口缝是面部本身的浅层几何。

- 基础形体：颅骨、颧颊、下颌，不显示五官细节。
- 五官平面：在固定网格上建立鼻梁鼻尖、口缝和耳部。
- 眼眶布线：替换预留面片，建立十点杏仁形开口和内收眼睑边环。
- 耳朵为独立封闭分块，以重叠方式接入，尚未焊接。
- 眼眶为两个真实开放边界；深灰部分是头壳内表面，非眼球、非封口片。
- 没有平滑细分。逻辑线框不显示三角化的对角线。材质按面着色。
- 42 项结构参数分为七组，每项均有滑杆、数值输入、范围与说明。按阶段启用，尚未生成的结构不允许调节。
- 支持分组重置、全局重置、显式保存/载入本机参数和 v2 JSON 复制/导入。刷新默认复位，需点击载入恢复；跨设备请使用 JSON。

三个阶段是形体/特征递进，不是三种独立面数预算。基础笼架预先保留了后续五官站位。

## 检查与限制

- 新增测试覆盖三阶段、参数上下界、镜像、有效坐标、三角面非退化、边使用次数、相邻绕序以及眼眶开放边界。
- 90 项项目测试通过，TypeScript 检查及 Vite 构建通过。逐项检查参数确实作用于对应阶段；另检查全最小、全最大及 150 组确定性随机组合，覆盖有限坐标、三角面非退化和相对默认面的局部翻面。该检查不等于完整自交检测或美术验收。
- 浏览器验证数值输入、保存→重置→载入、JSON 生成与导入。
- 云预览浏览器禁用 WebGL，自动切换 Three.js SVGRenderer 兼容模式。已用该模式检查正面、侧面、45°和阶段切换；不能将这些检查称为 WebGL 实渲染验收。
- 支持 WebGL 的浏览器优先使用 WebGLRenderer；兼容模式使用同一份网格和相机，但排序、阴影及线框显示存在渲染差异。
- 响应式布局及 OrbitControls 支持触摸旋转缩放；尚未在真实手机验证。
- 本轮据侧视结果修正耳朵厚度和鼻唇前凸，后续优先用用户认可的少年正侧参考继续校准，再进入眼球与表情。

## 结构补齐原则

少年风格保留较完整颅顶、简化眉弓、清楚但不夸张的颧颊转折、小型连续楔形鼻、浅唇面与有宽度的下巴。眼裂必须有内外眼角及上下眼睑，不能用贴在球面上的独立几何体替代。下颌宽度和下巴宽度独立，避免整个下半脸收成针尖。以上为本项目的美术取向，不是唯一的二次元人体比例。

优先顺序：正面轮廓→侧面额鼻唇颏关系→45°颧颊和眼眶→局部眼睑。先调整颅骨/下颌，再调眼距与眼裂，然后鼻口；每轮保存一份 JSON，避免多个方向同时盲调。

`parameters.js` 是参数定义的单一来源；`parameterPanel.js` 管理 UI 与存储，`boyHead.js` 用连续局部权重移动控制点，镜像生成。新增控制应保持拓扑不变、左右对称，并证明其在指定阶段确实生效。不得用加细分或大量随机顶点代替结构。

数值中的 1 为倍率基准，0 为偏移基准；偏移使用模型局部坐标（不是厘米）。这些范围是针对当前笼架的编辑范围，并非文献测量值。眼距偏移为每侧位移，双眼中心距离变化约为两倍偏移。嘴角抬高是静态造型参数，不是表情系统。

## 吻部体块补充

吻部独立于唇面参数：覆盖鼻底至下唇的口周区域，中央前面向前建立体积，左右通过斜面接面颊，下方以浅颏唇沟与下巴分开。在原有控制网格鼻尖与上唇之间补一排局部鼻下站位，不增加全局细分，不添加浮动嘴部物体。分区色中，灰紫为鼻底面、棕色为人中面，橙色为吻部正面，深橙为两侧转折，灰绿为下唇至下巴过渡。

吻部控制：前凸默认 0.045、宽度/高度默认 1、颏唇沟内收默认 0.012。鼻尖、下巴和眼眶不随吻部整体向前移动。已有 mouthForward 是较窄范围的嘴部细调，两者叠加仍应检查侧面。旧 v2 JSON 缺少新字段时使用新默认值，因此载入旧预设会增加吻部的默认体积。

验证：90 项测试通过；包含全部 42 项参数和 152 组组合检查。兼容预览模式检查 45° 分区与侧面体积。最终美术仍需按用户参考校准。

## 鼻下与吻部的连接修正

此前鼻尖到上唇只有一段面，口周前凸的影响范围又延伸到该处，导致侧面连成斜坡。现在在 y=-0.30 增加局部控制排，形成鼻尖→内收鼻下点→上唇的折线，分别建立 nasalBase 与 philtrum 分区；边缘与面颊共用控制点，仍为连续闭合皮肤。没有切开网格或添加悬浮零件。

吻部前凸和嘴部前凸的权重在鼻下排归零；新增 philtrumInset（鼻下转折内收，0～0.03，默认0.015）独立调整这一层。默认中线鼻尖 z=0.82、鼻下点 z=0.655、上唇 z=0.725。此数值是当前项目控制笼坐标，不是人体测量标准。

新增回归测试检查鼻底和上唇之间的凹折，以及口周前凸不推走鼻下排和鼻尖。当前预览浏览器访问受限，本轮尚未完成渲染视觉验收；旧版的视觉检查不能作为这次新增布线的验收。

## 镜像三角化修复

此前镜像面直接反转整个顶点数组，改变了四边形/多边形扇形三角化的起点，使两侧控制点对称但渲染对角线、面法线和局部凹凸不一致。现在固定首顶点，只反转后续顶点，保持镜像后的三角划分完全对应；耳部采用相同规则。鼻下面颊过渡去除五边形扇形切分，改为围绕局部边界点的三个明确三角面，保持共享边闭合。

新增测试先在旧代码复现不对称，再验证所有渲染三角面及法线的镜像对应（包含三个阶段和吻部调整预设）；90 项测试和构建通过。另用实际网格做正面、45°、侧面软件光栅化检查，正面在对称光照下左右一致。这是几何诊断图，不能替代浏览器 WebGL 材质的视觉验收。

## 下颌线与枕部体积修正

保留现有拓扑预算，将原水平下半脸控制排重新按解剖方向排列：第 1 排从前方下巴向耳下下颌角逐渐抬高；第 0 排向内收，形成独立下颌底面；第 2 排及以上保留腮部侧面与面颊体积。结构分区新增 jawUnderside，颜色较深。它是真实几何折面，不是绘制轮廓线。鼻口中线控制点保持原高度。

后脑按高度重设前后厚度，最饱满处约 y=0.36、z=-1.16；上方逐渐收向颅顶，下方平滑收向耳后和颅底，避免整体等比例拉伸造成直立后壁或下部台阶。原 backDepth、jaw 等参数继续叠加在新基础形上，42 项参数数量不变。旧预设加载到新基础形后的外观会改变。

验证：90 项测试及构建通过，包含下颌边缘上扬、下颌底面内收、枕部饱满度、三角面镜像、极值和随机组合；用实际生成网格做正面/45°/侧面软件光栅化检查，并修正初稿后脑下部突变。当前未完成浏览器 WebGL 实渲染验收。

## 耳廓厚度

耳廓由原来的外沿直接收向背部中心，改为外沿、独立背沿、七块四边侧壁和封闭背面。默认外沿至背沿的横向厚度至少 0.08 模型单位；较突出的耳轮更厚，背沿保持在耳窝底部内侧。耳窝凹面保留，耳根仍以重叠方式接入头壳，尚未焊接。结构分区区分 earWall 和 earBack；现有大小、高度、外展控制继续生效，参数数量不变。

91 项测试和构建通过，覆盖侧壁厚度、闭合性、镜像及组合形变；用三视角网格诊断检查了厚度效果，尚未在浏览器 WebGL 实渲染复核。
