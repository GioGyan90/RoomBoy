# 少年头部建模实验

入口：`?view=head`。人体结构研究页和人物审阅工具栏均有链接。

## 范围

纯 JavaScript + Three.js 生成，无外部模型、头发、颈部、眼球。当前为静态通用少年造型，尚无用户确认的正侧设定图，不宣称精确临摹或已达到角色最终美术标准。

代码：`src/experiments/head/boyHead.js`（逻辑笼架、镜像、网格生成）、`headLab.js`（独立实验页）、`headLab.css`。

## 方法

继承 STRUCTURE_STUDY.md 的“比例→体块→必要布线”和多角度检查。头部使用解剖站位而非球体变形；面部半边控制网格和后脑截面共用太阳穴边，镜像时焊接中心线。鼻部和闭合口缝是面部本身的浅层几何。

- 基础形体：颅骨、颧颊、下颌，不显示五官细节。
- 五官平面：在固定网格上建立鼻梁鼻尖、口缝和耳部。
- 眼眶布线：替换预留面片，建立十点杏仁形开口和内收眼睑边环。
- 耳朵为独立封闭分块，以重叠方式接入，尚未焊接。
- 眼眶为两个真实开放边界；深灰部分是头壳内表面，非眼球、非封口片。
- 没有平滑细分。逻辑线框不显示三角化的对角线。材质按面着色。
- 五个参数只在页面会话内有效，刷新恢复默认；暂未提供持久化或导出。

三个阶段是形体/特征递进，不是三种独立面数预算。基础笼架预先保留了后续五官站位。

## 检查与限制

- 新增测试覆盖三阶段、参数上下界、镜像、有效坐标、三角面非退化、边使用次数、相邻绕序以及眼眶开放边界。
- 84 项项目测试通过，TypeScript 检查及 Vite 构建通过。
- 云预览浏览器禁用 WebGL，自动切换 Three.js SVGRenderer 兼容模式。已用该模式检查正面、侧面、45°和阶段切换；不能将这些检查称为 WebGL 实渲染验收。
- 支持 WebGL 的浏览器优先使用 WebGLRenderer；兼容模式使用同一份网格和相机，但排序、阴影及线框显示存在渲染差异。
- 响应式布局及 OrbitControls 支持触摸旋转缩放；尚未在真实手机验证。
- 本轮据侧视结果修正耳朵厚度和鼻唇前凸，后续优先用用户认可的少年正侧参考继续校准，再进入眼球与表情。
