# 概念图复现与验收记录

## 来源与边界

本次只使用用户提供的两张概念图作为对照。运行时的房间、人物、服装、头发、家具、织物、窗外景观全部由 TypeScript 生成，没有下载人物模型、贴图或其他美术资产。原图不上传到公开仓库。界面的对照功能通过本地文件选择器读取图片，仅在当前浏览器使用，不会向服务端提交。

单张概念图没有提供背面、侧面或实际尺寸，因此这些部分由建模参数推断。本次是可转动、可继续编辑的三维近似复现，不能声称已与二维原画完全一致。

## 实现

- `sculpt.ts`：平滑截面网格、参数曲面、圆角结构、曲线管道和渐尖发束。
- `character.ts`：完整人物关节接口；下颌/颧骨/鼻部的连续表面；杏眼、上下眼睑、眉毛、唇线、耳廓与耳环；多层分束发型；背心、短裤、缝线、项链；上臂、前臂、大腿、膝部、小腿、脚踝、足弓、五指、脚趾与指甲。
- `roomDetails.ts`：床架、垂落床单、被褶、枕边、收纳箱；扎帘、纱帘和窗框；衣架与成衣曲面；键盘、触控板、杯柄、笔、台灯关节、电线；曲面椅背；垂叶、背包和地毯。
- 渲染：太阳投影、暖色补光、SSAO 接触阴影、分阶漫画着色与细轮廓描边，保留真实三维结构。
- `poseIK.ts`：双骨骼解析 IK，让参考站姿的手落在腰部附近。
- `review.ts`：游玩、房间、人物、脸部四种视图，以及概念图悬浮对照。

## 实际检查与修改

已检查多轮房间/全身/脸部截图，另检查默认游玩视图。检查中发现并修复：衣柜遮挡书桌、床单与被子相交、眼睛过圆、发束细碎、鼻部单独曲面边界明显、短裤边缘露肤、手隐藏在躯干内、衣物上缘突起。最后继续完善了足部连续网格和膝踝细节。

实际渲染使用 Chromium + SwiftShader，页面无运行异常。点击角色可打开六种互动菜单；“使用电脑”可以运行；房间/人物/脸部切换和原图对照均可操作，参考图片成功加载。

六项自动测试通过，包括全部可替换房间资产组、所有模型顶点有限性，以及六种动作各推进 500 帧后的关节矩阵有限性。生产构建通过。

## 尚存差异

- 人物脸型、发型细节、肌肉表面与原画的绘画概括仍有差异，当前不能视为最终角色雕刻。
- 原画的笔触、局部线条粗细、手绘明暗与窗外景深没有逐像素匹配。
- 家具比例、遮挡、站姿和透视经过对照调整，但单视图重建未达到摄影测量意义上的一致。
- 肢体当前由连续截面构件配合关节组合，完整连体蒙皮与身体/衣物碰撞尚未实现。极端姿势需要继续检查。
- SSAO 增加显卡负担，移动端性能尚未实机验收。原版家具碰撞和寻路仍未实现。

## 查看

在线页点击右上角“房间”“人物”“脸部”，再点击“概念图对照”，从本地选择对应参考图片。查询参数 `?view=room`、`?view=character`、`?view=face` 可直达相应视图。`&capture=1` 隐藏 UI 并固定呼吸动画时间，便于截图比较。
