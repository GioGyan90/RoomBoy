# RoomBoy 少年头部：真实分区约束 QEM 第一轮（10K）

> 状态：**实验候选，通过几何与自动轮廓检查；不替换默认 34,500 面母版。**
> 目标：在不增加替代颅骨壳、非共边五官贴片的情况下，从原始源三角形进行分区边折叠，并在 X=0 精确镜像。

## 母版、拓扑实测

- 原始：`public/heads/grey-head-qem-symmetric.glb`，31,357 顶点 / 34,500 个三角面，保持原文件字节不变。
- 分块：`grey-head-qem-symmetric.parts.glb` 和 `parts.json`，23 个真实网格分区，保留原始源面索引，**均未修改**。
- 原始索引边：65,795 条；只有一个面的开放边 **28,090** 条；非流形边 0。
- 合并坐标后仍有 28,018 条单面边；证明大量不连续源自原始 QEM 网格，而不仅是材质/法线硬边。
- 原始中线：655 个顶点、593 条边，无不成对的中线边。
- 原始跨区共边：1,714 条（负 X 侧 857 条）。
- 23 区按原索引存在大量单片岛，空间标注并不是人工整理的连续环状拓扑。
- 严格锁住所有开放边、共享边、中线与全部高优先级面部顶点会锁定 **29,199/31,357 = 93.1%** 的顶点，无法合理达到 10K。

详细数字：`public/heads/grey-head-region-lod-v1.topology.json`；严格锁点/边清单：`grey-head-region-lod-v1.boundary.json`。

## 实际实现与结果

工具：`scripts/audit-head-region-topology.py`、`scripts/build-head-region-lod.py`、`scripts/render-head-region-lod.py`。

1. 从已存在的 23 区 faceIds 将每个源三角形直接映射到语义分区。
2. 仅负 X 半侧简化。原始区域交界边、X=0 顶点和中线边禁止折叠和移动。
3. 对五官转折处大角度法线、耳廓外缘、鼻尖、唇线和眼眶极值点锁点；曲率/边界平面加入 QEM 误差。
4. 开放边按特征敏感度谨慎允许边折叠，但须通过 link condition、角度与面积倒置约束；源网格的既有开放边数量**允许减少**，不能当成已经填洞或无裂缝的证据。
5. 完成各区减面后，直接用**同一组保留下来的原始全局顶点 ID**整合负 X 区域，共享边精确共用索引；以反向绕序精确镜像另一侧。单一统一 GLB 不重建额外的表面。
6. 同时从统一共享索引表导出 23 个独立 GLB 网格及可逆的 `globalVertexIds` 映射。**分块 GLB 供编辑，而统一 GLB 才是实际共边的单网格**。

| 指标 | 母版 | 第一轮 | 第二轮 / 当前 |
| --- | ---: | ---: | ---: |
| 三角面数 | 34,500 | 10,804 | **10,000** |
| 顶点数 | 31,357 | 12,297 | 见 JSON 报告 |
| 左右对称 | 是 | 是 | 是 |
| X=0 中线匹配 | 593 边 | 593 边 | **593 边** |
| 负侧跨区共享边 | 857 | 857 | **857 条保持不变** |
| 新增非流形边 | — | 0 | **0** |

最终约减面 **71.01%**；实际折叠 9,217 次。由于母版自身已有大量单面边，不能宣称结果为完全水密模型。

## 点到三角面表面误差（非最近顶点距离）

在两组实际源三角面上用等面积随机采样各 8,000 点（总共 16,000 点），通过 R-tree 寻找**对方三角面曲面上的最近点**，计算双向距离。计算脚本：`scripts/check-head-lod-surface.py`，详细指标存入 `grey-head-region-lod-v1.report.json`。

| 方向 | 均值 | p95 | p99 | 采样最大 |
| --- | ---: | ---: | ---: | ---: |
| 34.5K 母版 → 10K | 0.0050541 | 0.0222031 | 0.0419624 | 0.0824659 |
| 10K → 34.5K 母版 | 0.0047068 | 0.0272085 | 0.0510486 | 0.0920082 |

头高 2.2487391 个模型单位，双向 p95 最大值为 0.0272085（头高 **1.21%**），双向采样极大值为 0.0920082（**4.09%**）。不等于严格 Hausdorff 距离上界，不能仅因均值较低就断定耳廓/眼睑的形状完整。

### 真实 Three.js 材质检查

与纯 CPU 投影的平面法线不同，浏览器用实际 GLTFLoader 解码出的源顶点法线和 MeshLambertMaterial 进行对照。第一轮 WebGL 截图显示新 10K 在颅顶和耳部局部视觉表现不同；眼眶、嘴唇等形体需用户在交互预览里最终确认。已修复侧视时左右模型沿视线重叠的比较布局，改为沿相机屏幕水平轴排列，且同步更新比较标签。

**验收分级：**达到精确 10K、共享索引与镜像的工程验收；人眼外观验收保留为可交互实验版，不替代已批准的 34.5K 母版。
