## 本次必须避免的旧版错误

已移除的失败方案曾输出 10,000 三角面、7,710 顶点、约 306 KB，但采用了 **5,600 面按径向射线重建的颅骨底壳 + 4,400 面原模型眼鼻口耳局部 QEM 面片**。单纯按面数验证未能保证视觉效果：前期普通 QEM 出现破洞；后期混合壳让颅骨轮廓变得不够真实，五官与支撑壳不共边、有重叠与潜在穿插，用户否定了结果。**不要把这版当作成功的验收依据**。

## 推荐的实际工作顺序

### 1. 先审计各结构块的拓扑

用母版 GLB 与 parts.json 还原全局邻接关系，统计每个区域的连通分量、真实开口、共边、碎片岛、法线硬边、退化面和非流形边。

特别注意：同位置、不同法线的重复顶点可能是原模型有意设置的硬边。需要使用顶点映射、几何位置和面邻接一起判断，不能机械把所有重合顶点合并。

已拆出的 23 区中，部分边界是空间标签形成的锯齿，并非天然的面环。先把它们整理到更合理的曲率变化处，保持每一个原三角面仅分配给一个区，并保持左右对应一致。

### 2. 标记并锁住关键边和共享边

先建立**区域间共享边界图**，给各块记录共享边/顶点的统一全局索引。重点保护 X=0 中线，眼眶开口、眼睑眼角、眉弓、鼻梁和鼻翼、口缝与唇峰、颧骨外转、下颌角/颏尖、耳轮/耳甲腔、耳根厚度及正侧轮廓。

首轮简化中，区域交界边和中线边不要擅自折叠或移动。如果锁定后无法压到目标，则单独设计**跨区域同步简化边界**：只允许在所有相邻区域同步更新共同边界，绝不能每块各删各的造成裂口。

### 3. 分区减面，而不是重新生成颅骨

以实际源网格做受边界保护的 QEM / 曲率感知边折叠。优先在负 X 侧计算，再按完全相同的顶点和三角面映射镜像正 X，保持严格对称。

可以试用以下 **总计 10,000 面**的初始弹性预算（只是起点，须按实际视觉/拓扑误差调整）：

| 区域 | 母版面数 | 目标参考 |
| --- | ---: | ---: |
| 颅骨（颅顶/后脑/额部/颞侧等） | 20,988 | 3,700 |
| 眼眶及眉弓 | 3,050 | 1,700 |
| 鼻部 | 1,706 | 800 |
| 面颊 | 916 | 500 |
| 口唇 | 702 | 450 |
| 下颌 | 2,662 | 1,000 |
| 耳部 | 4,476 | 1,850 |
| **合计** | **34,500** | **10,000** |

**不得牺牲眼眶、鼻尖、口缝、耳廓或头部外轮廓来机械完成配额。** 如果保护边界后达不到一万面，应保存最佳可用结果和数据，明确反馈阻碍，再调整分区与全局共边策略。

### 4. 拼成真正统一的头模

将已经分别简化的区域沿**统一的共享边界顶点和索引**拼接。合并后再完成 X=0 对称焊合，统一三角面朝向与法线处理；保留必要的硬法线，不添加重叠的第二层头壳。避免将 23 个没有共用拓扑的 Mesh 直接拼在一起就当成单一完成模型。

要区分母版已有的独立面/洞和新减面引入的裂缝；不能凭“视觉看起来封上了”就宣称焊接或水密成功。

### 5. 导出、测试、截图、发布

- 新成果用新文件名，如 public/heads/grey-head-region-lod1-10000.glb；同时可以导出相应 23 分区版及映射 JSON。**不要重用废弃的 grey-head-lod1-10000 文件名**。
- 编写新的生成脚本及回归测试：总面数 ≤10,000，左右位置/三角形镜像，中心线及分区共边无意外裂缝，无法线/索引异常、非有限坐标、退化面或局部严重翻面。
- 对比原 34,500 面母版：正、45°、侧、背和关键五官局部，建议同时开启线框。量化表面距离、轮廓误差并逐张检查截图；不要把最近源顶点距离误当作曲面误差。
- 在真实结果通过检查后，才增加预览切换/并排对照；保持现有分块检查功能与未修改母版。
- 更新文档并提交、合并；运行 npm test、npm run build；核查 GitHub Actions 和 Pages 成功后提供部署 URL。
