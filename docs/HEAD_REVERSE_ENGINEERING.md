# RoomBoy 少年头部逆向工程：真实网格结构分块（v1）

入口：[结构分块实验室](https://giogyan90.github.io/RoomBoy/?view=head&mode=parts)

## 本轮目标与约束

这项工作以 **已验收的精确对称 GLB** 为母版：
`public/heads/grey-head-qem-symmetric.glb`，31,357 个源顶点、34,500 个真实三角面。
它来自用户上传的 1,424,998 面 `grey-head-fast-medium(2).glb` 经 QEM 减面，再切半、镜像和焊接中线。

当前不是“重新画一张脸”、不是把三角面按颜色覆盖、也**没有再执行减面**。
目标是保留实际三角网格与边界信息，同时把面片组织为可单独检查和编辑的结构区域，为下一轮针对不同部位设置简化优先级打基础。

## 逆向拆解流程

1. **读取三角面而不是重新构形**：使用原对称 GLB 的 `POSITION`、`NORMAL` 和索引缓冲。模型坐标是 `+Y` 向上、`+Z` 朝面部、`X=0` 为左右对称面。
2. **分配语义标签**：按照面中心点的位置与预设的眼眶、额部、鼻口、耳廓、后脑范围，将每个**源三角面**归到一块。左右配对区域统一使用 `abs(X)` 判定，再根据 `sign(X)` 镜像命名。
3. **形成独立网格**：每块提取自己的真实顶点和完整三角面，局部重新编号。内部位置/法线保留源数据；分块边界处会保留**位置相同的独立顶点**，使每块能够单独修改，而不是在原始母版上直接切断已有共享顶点。
4. **记录可逆索引**：`parts.json` 中每一块的 `faceIds` 是母版三角面编号，`sourceVertexIds` 是该块局部顶点对应的**母版顶点编号**。因此可以把每个局部三角面重新映射回原始顶点，验证面片没有被翻转、遗漏或重复。
5. **双向检查**：自动测试读取仓库里的实际二进制 GLB，逐个复原所有三角面及顶点，检查左右配对面数、分块总面数、位置及源法线是否逐值一致。

**边界定义属于逆向分析的第一版近似语义标签**：使用空间范围划分，某些边缘可能呈阶梯状，个别区域可能有不连续面片。它不等于 Blender 中经过人工修正的最终面环或解剖标准，也不说明已经获得可直接做表情绑定的拓扑。

### 网页分析

使用 `?view=head&mode=parts`：

- **整体 / 分块切换**：与原来的对称母版、源高模对照模式可互相切换。
- **分离距离**：只移动可视化副本，方便做爆炸图；不会改变母版或导出网格。
- **七个家族、23 个部件列表**：逐块勾选显示/隐藏、查看源面数。
- **聚焦 / 仅显示选中 / 分块边线**：检查眼部、鼻翼、嘴唇、耳朵和后脑的局部连接。
- **导出选中 GLB**：可下载一个实际独立网格，后续在 Blender 或其他工具中继续处理。
- **下载全部 GLB 和映射 JSON**：分块后可以保存源索引，还可以用 JSON 重新组合模型。

## 下一轮如何继续简化

**建议按两阶段推进，而不是立即把所有部位按一个比例统一减面。**

### 第一阶段：边界与拓扑复查

- 先固定眼眶开口、眼睑边、鼻翼根部、唇缝、下颌轮廓和耳甲腔的不可折叠点位。
- 检查当前空间标签造成的零碎岛屿和锯齿边界，将分界线调整到面部真实曲率转折或稳定面环附近；**新的面片分组不应改变或删除源网格三角面**。
- 严格保持 X=0 左右镜像，左右配对的每次边界调整在另一侧同步。
- 记录每块邻接边的位置、顺序和索引；后续独立减面时锁住共享分块边界，最后重新拼接避免裂缝。

### 第二阶段：按面部重要性分配 LOD 预算

以下数字是**待测试的目标建议，不代表已生成或验收**：

| 部位家族 | 当前面数 | LOD1 可尝试预算 |
| --- | ---: | ---: |
| 颅骨 | 20,988 | 6,000 |
| 眼眶 | 3,050 | 1,800 |
| 鼻部 | 1,706 | 1,000 |
| 面颊 | 916 | 600 |
| 口唇 | 702 | 500 |
| 下颌 | 2,662 | 1,500 |

对照原始母版做正面、侧面、45°、背面与局部阴影检查，逐区检查 Hausdorff/点到表面距离（不要用“最近源顶点距离”替代曲面误差），最后再决定哪些区域适合大幅减面。**眼眶/耳廓/嘴部首先保护形体与拓扑，后脑和颅顶优先压缩。**

## 构建与回归

```bash
npm ci
npm run assets:parts
npm test
npm run build
```

`npm test` / `npm run build` 会自动重新生成 `.parts.glb` 与 `.parts.json`，保证它们与当前对称母版及语义规则一致。测试验证 34,500 个母版三角面恰好被分配一次，重建每块三角面的原索引和顶点位置/法线都与源 GLB 相同。
