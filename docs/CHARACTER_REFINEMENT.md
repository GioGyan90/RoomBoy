# 角色第二轮细化：根据正侧背设定图

依据用户补充的三视图与面部特写继续调整；参考原图不随公开仓库上传，仍可在页面通过本地选图对照。

## 轮廓与比例

- 肩胸上移，头部缩放至更接近约七头身的成年人比例；缩短下颌与肩颈之间的距离。
- 上臂、前臂、大腿、小腿与手部收细，保持肌肉截面的起伏和关节位置。
- 缩短短裤裤腿与裆部，调整黑色裤口和侧缝线。
- 脚跟补成闭合网格，修正背视图中的脚跟开口。

## 面部与头发

- 下颌、下巴、眼眶和鼻部重新校准；眼部整体内收，眼白使用双面曲面避免左右不一致，收窄睑裂并压低虹膜纵向高度。
- 眉毛改为渐尖体积，调整眉峰和嘴角，让表情更接近设定图。
- 发束单独拆到 `src/assets/procedural/hair.ts`，用沿头皮法向展开的薄刃截面替代圆管形发束。
- 补齐后脑、耳后和后颈的底层覆盖；打散梳齿状末端；增加斜向后发层、分缝和少量冠部翘发。
- 黑发改用较柔的高光，避免整片无层次的纯黑，也避免过强的塑料感。

## 服装与饰品

- 增高背心背面领口，保留前侧低领与侧面袖窿。
- 按新图改成两条链：短链小圆饰与长链矩形吊牌；链路沿颈胸轮廓重新布置。
- 移除上一版耳环，新图的耳部没有该饰品。
- 肩位变化后微调使用电脑时的上臂和前臂角度。

## 检查方式

人物和脸部检查视图新增“正面 / 侧面 / 背面”按钮；参考站姿改为自然垂臂，便于与三视图比较，不再固定为双手扶腰。

查询参数示例：`?view=character&angle=front`、`?view=character&angle=side`、`?view=character&angle=back`。参数 `capture=1` 供截图验收使用。

已分轮检查全身和头部的正、侧、背面实渲染，并根据发现的问题继续修正。自动测试覆盖完整房间资产、模型顶点和六种动作中的矩阵有效性；生产构建与全部六项测试通过。正面、侧面、背面按钮、本地参考图加载与电脑互动已在浏览器中验证，未发现页面运行错误。

## 仍有差异

这仍是程序生成的三维模型，尚未逐项复刻原画的手绘明暗、发丝密度、眼部气质与肌肉表面。当前肢体沿用分组关节结构，极端动作下仍需检查身体与衣物的穿插；本轮不把它标记为与原图完全一致。
