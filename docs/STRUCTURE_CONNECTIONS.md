# 颈胸与臀腿连接修订

本轮继续使用 1536 × 1024 彩色几何体块简化图。将颈胸与臀腿分别放大，对照正、侧、背面；没有新增未经约束的局部概念图，也没有使用原始精细人物设定替代当前基准。

## 问题与处理

此前颈部、胸腔及臀部、大腿是相交的闭合体。放大后，颈根的直筒感、骨盆下缘的外翻台阶和腿根突兀的交叉面更加明显。

- 颈胸：统一为 16 点边界。颈部前侧两组斜面向胸骨上凹口收拢，颈根向两侧展开，后方连接肩背；胸腔顶圈直接使用颈根的真实顶点坐标。
- 臀腿：骨盆下缘重建为前后不同曲率的弧形开口，修正后凸截面位置。将这一边界分成左右腿口，共用短裆底桥；每侧大腿上端逐点连接对应腿口，额外一圈沿腿口曲线过渡到大腿。
- 去掉颈部底盖、胸腔顶盖、骨盆底盖和大腿顶盖，避免内部封口面横穿接缝。每个连接组合整体闭合，各子网格在接缝处不再各自闭合。

连接逻辑集中在 bodyJoins.ts；截面仍在 bodyReference.ts，局部颈前分面在 bodyStructure.ts。独立子网格保留各自材质和缓冲区，接缝坐标逐点一致；没有声称已完成全身共享索引焊接或动画蒙皮。

## 放大检查

检查页新增“全身 / 颈胸放大 / 臀腿放大”。焦点可与正、侧、背、前斜侧、后斜侧及线框、剪影组合。当前简化图仍通过本地文件选择加载，局部观察也支持正交参考叠合和并排。三视同屏在窄屏下优先保证宽度，单方向局部视图更适合近看。

离线导出工具 tools/export-join-study.ts 输出颈胸、臀腿各一组“简化图 / 实际网格”三方向局部技术图。输入参考和输出图片均不提交公开仓库。

## 验证与边界

- 12 项自动测试通过，生产构建包含 TypeScript 检查。
- 测试以连接组合检查几何闭合，确认每条边恰有两个方向相反的邻面；检查内部盖面移除、三角形无退化，以及两种密度下的兼容性。
- Chromium + SwiftShader 完成两处局部各五个视角检查；本地简化图、放大切换、并排、线框、剪影和手机界面无脚本错误。
- 当前体块 2,244 面，后续密度 2,700 面。关节中心 RMS 不变，但它不度量局部轮廓或肌肉形态，也不是本轮连接细节的验收标准。

仍有差异：颈前肌肉转折和臀沟深度是低面近似；肩臂、膝部等接口尚未按本轮方式重建；尚未验证关节弯曲时的蒙皮。旧版可玩人物不受本次结构研究修改影响。
