# 点位校准 · 第二阶段（历史记录）

最新执行与验收见 [MESH_ALIGNMENT.md](MESH_ALIGNMENT.md)。本页保留上轮手工坐标与不足；最新标记已改为从实际网格读取，背面另有独立读点。

本轮维持体块分组，重新建立定位数据。约束来自原始设定的手工读取，不是从生成简化图再次猜测，也不是自动拟合精度报告。

## 上轮问题与修改

- 上轮胸腔较宽，尤其肩部与上胸关系过于方正。按原图截面收窄胸腔，重新连接颈根、肩带和三角肌。
- 上轮大多数体块以相近的 Z 坐标居中，侧面失去了原设定的头颈前移、胸背曲线与髋部前移。现在侧面轮廓的前后点直接控制各截面的深度和中心。
- 肘、腕的高度偏低，手掌偏外。肘部定位从上轮约 1.12 提到约 1.17；腕部从约 0.90 提到约 0.93。掌部向髋侧收回，保留左右站姿差异。
- 双脚原来接近平行；现在足部在不同高度使用不同的横向中心，匹配原图前掌向外的姿态。
- 髋腿交界向上衔接，骨盆下缘倾斜。仍是相交的封闭体块，没有把它误称为连续变形网格。

## 坐标约定

原图尺寸 1200 × 800；地面行 y=772；头顶 y=24；设计身高 1.80。正面轴 x=554，侧面踝部参考轴 x=821，背面显示轴 x=1042。

换算：X=(正面x−554)×1.8/748；Y=(772−y)×1.8/748；Z=(821−侧面x)×1.8/748。

X、Y、Z 的定位不再散落在模型代码中。`bodyReference.ts` 同时保存关节约束 `sourceJoints` 和表面截面 `bodyBands`；`bodyBlockout.ts` 从这些坐标建立两种密度。关节中心与轮廓边缘是两类数据，不把肩关节中心称为肩峰，也不把衣物边缘视为裸露身体的真实边界。

## 在检查页复核

1. 打开 `?view=structure&points=1`，可切换正面、侧面、背面和三视同屏。
2. “参考图”里选择本次原始设定图（1200 × 800）。页面会将它按固定坐标裁出三视图并与模型叠合。文件只在浏览器读取，不会上传。
3. 再点“参考图”收起侧栏，观察体块和原图。可用“原图叠合”切换，并调节叠合强度。
4. “定位点”显示编号、连接线；侧栏可以展开查看相同编号的坐标表。标记是建模约束，不能把标记与原图重合当成网格已经完全准确。
5. 其他尺寸的参考图仍可旁置显示，不能使用本图的固定裁切坐标。1200 × 800 的其他布局也不适用，需要用户选对原图。

当前正面肩胸、手臂及脚部轮廓，以及侧面头颈、手腕与髋膝踝的前后关系已做两轮叠合检查。背视图与正视图存在原画姿势、发型和透视差异，没有为追逐背面像素另建一套互相矛盾的身体。

## 验证边界

两阶段分别为 1,312 / 1,968 三角面。自动检查除闭合与有效性外，验证两个密度的正侧面截面极值确实来自同一组像素数据，防止换密度时重新偏移。此项测试只证明坐标使用一致，不能证明人工读点没有误差。

被衣物遮挡的腰胯、后脑发包和肩背转折仍需继续人工校准；本轮不宣称逐像素复现。没有添加五官、发丝、衣褶等表面细节。
