# RoomBoy · 黑金邮轮舱房卫浴 — 低模素材分组与装配规范

参考：用户提供的「黑金邮轮舱房·卫浴区拆解」概念图（2026-11-10）。
目标：低面数游戏美术，日漫感、温暖黑金与象牙陶瓷；优先真实开口、
真实接触关系、人物可以通过的动线，再加入装饰。

## 素材与 UV

- 黑金大理石：**纹理只绘制到墙、地和台面的 UV**，低饱和黑底、少量细金脉，
  不生成浮空直线和条带。
- 象牙陶瓷：主体以几何表达倒角、翻边、盆内凹和排水；微小光泽差异交给材质。
- 香槟金：仅管件、阀门、把手、真实连接座使用实体；表面蚀刻用 UV。
- 胡桃木：柜门与抽屉真实开口，木纹沿长轴；避免把独立柜体做成一整块方盒。
- 镜面：低粗糙度材质，镜周的光用连续边缘曲面或纹理，不作悬浮光柱。
- 资产需有稳定名称、合理 pivot、世界单位（m 近似量纲）及独立渲染检查机位。

## 分轮安排

1. **本轮 — 资产拆组和基础形修整**：模块独立，收束材质，强化浴缸的
   内壁/缸沿与马桶曲面，补真实排水盖，保持既有命名与动线。
2. **第二轮 — 墙面、门与地面**：结构开口与门扇厚度、整体内外检查，消除
   黑色墙面多层贴片；完善金脉 UV 和地漏。
3. **第三轮 — 洗手台 / 淋浴系统细化**：重建壁挂件的连续弯管、
   台盆开孔边缘、开放木柜与叠放毛巾；增加连接性测试。
4. **第四轮 — 多机位视觉验收**：浴缸前/背、顶部、盆内、马桶近景、
   门内外、花洒两侧；再检查人物从入口到卫浴、马桶的可达性。
