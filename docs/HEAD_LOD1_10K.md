# 少年头部 LOD1 · 第一轮 10,000 面简化

在线对照：[头部实验室 · LOD1](https://giogyan90.github.io/RoomBoy/?view=head&lod=1)

## 文件与版本

- **不可覆盖的对称母版**：`public/heads/grey-head-qem-symmetric.glb`，34,500 面、31,357 顶点。
- **独立 LOD1 副本**：`public/heads/grey-head-lod1-10000.glb`，**10,000 面、7,710 顶点，306,108 字节**。
- **LOD1 的 23 个可编辑结构分块**：`public/heads/grey-head-lod1-10000.parts.glb`。
- **LOD1 的分块索引、包围盒及来源记录**：同名前缀 `.parts.json`、`.parts.audit.json`、`.report.json`。
- 原始 30K QEM、严格对称 34.5K 母版及母版的 23 分块版全部保留。

相对 34,500 面母版，LOD1 减少约 **71.0%** 三角面；相对最初上传的 1,424,998 面高模减少约 **99.3%**。这是**第一轮视觉试验版**，不是已经完成游戏骨骼绑定的低模最终版。

## 为什么不是统一 QEM

母版来自高模 QEM 和对称切割，包含大量彼此不共享索引的小面片、硬法线边界和细碎曲面岛。简单对每一块执行统一 QEM 或直接以半边锁定边来折叠三角面，虽然可以达到约 10,000 面，但渲染检查会在**额头、眼周、后脑、下颌产生明显孔洞与破碎面片**。为了避免这类缺损，本轮放弃把“原始顶点全部保留”当作唯一目标，采用**可追溯的混合 LOD**：

1. 利用 34.5K 对称母版表面射线采样，重建一个**封闭、连续的低面颅骨支撑表面**，以避免微小面片脱落导致的通透孔洞。
2. 在眼周、鼻、唇和耳部，对源模型实际三角网格再分别进行 QEM，避免仅靠平滑颅骨壳完全消除五官。
3. 支撑表面在五官附近沿半径内收约 0.018 个归一化模型单位，避免被源五官面片覆盖时发生严重 Z-fighting。
4. **严格镜像**：颅骨的正 X 半边由负 X 采样位置反射得到，且正负两边的三角形对角线也互为镜像；五官 QEM 仅处理负 X，再由同一几何镜像得到正 X。
5. 将五组几何烘焙到一份真正的 Three.js 可加载 GLB；按上一轮 23 项几何结构规则重新分组，生成第二份 LOD1 `.parts.glb`、索引映射与对称审计。

## 已核验及尚需改进

- **自动验证**：构建结果为 10,000 个真实三角面；原 34.5K 模型原样保留。LOD1 的 23 分块文件必须涵盖全部 LOD1 三角面，且每一面恰好分配一次。
- **严格左右一致**：LOD1 使用半边镜像位置与三角面，七组左右分块的面数对应相等。
- **三视角检查**：正面、45°、侧面的本地渲染显示，新的连续颅骨支撑壳消除了简单 QEM 的大片孔洞，眼眉、鼻口和耳廓仍可辨认。相比母版，颅骨折面会更柔和，眼睑和口唇的边缘有一定损失。
- **不是无损减面，也不是已经焊合为单个拓扑体**：眼鼻唇耳原网格面片仍叠放在支撑壳外侧。视图外观比较完整，但支撑壳和特征面片之间**存在重叠而非共享拓扑边**。这在后续表情绑定、拓扑细化前仍需重新整理和焊接。不要把 LOD1 当作 watertight、闭合无交叉的单一拓扑最终模型。
- 这里的 `.parts.json` 的 source-face 编号指向**新的 10K LOD1**，不是 34.5K 母版；因为壳体经过射线重建、五官再次减面，所以原始母版的全部面索引无法逐面一对一还原。

## 操作与恢复

实验室通过“查看 LOD1”切换显示新版本，通过“母版 / LOD1 并排比较”在共用相机下比较正面、半侧、侧面、背面。可导出独立 LOD1 GLB 或 LOD1 的 23 分块 GLB；原 34.5K 母版的查看、结构拆分和原始高模导入功能不变。

在具备 Python `numpy`、`scipy`、`vtk`、`trimesh` 与 Node.js 环境下：

```bash
python scripts/build-head-lod1.py
npm run assets:parts
npm test
npm run build
```

实际代码：`scripts/build-head-lod1.py`；GitHub Actions 的 `.github/workflows/head-symmetry.yml` 负责对称母版 → LOD1 → 两版各 23 个分块的二进制构建和提交。规则变动后重新烘焙可再检查面数与外形。

## 下一轮建议

1. **眼眶和嘴部**：去除支撑壳与源面片的重叠，尽可能沿真实眼眶开口、鼻翼外缘、口缝建立共用边与贴合过渡。
2. **下颌/额部**：优化射线壳的取样分布，重新增加关键折点，避免头部过度平滑。
3. **耳廓**：将正反面和耳根区分别规划拓扑，保留耳轮卷边和厚度。
4. **实际表面误差**：在母版与 LOD1 的正面/侧面/45° 等多个摄像机视角下，定量采样屏幕空间轮廓和点到表面误差，再决定 LOD2 的进一步简化阈值。
