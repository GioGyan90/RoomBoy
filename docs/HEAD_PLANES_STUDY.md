# Basic Planes of the Head — JS 程序化平面头模

入口：[\`?view=head-planes\`](https://giogyan90.github.io/RoomBoy/?view=head-planes)

## 参考与独立性

以用户提供的 **BASIC PLANES OF THE HEAD** 九角度平面头部参考图为造型目标（图上标注 veliscek.com）。本模块是独立的手工参数化 JS 建模，**不是**从参考图提取网格、不是减面自原有 GLB，也不是给游戏角色替换头部。参考图片不随仓库重新发布。

原仓库 \`?view=head\` 的 34.5K GLB 母版、23 个分区与 10K QEM 实验都不变。

## 代码

- \`src/experiments/head/headPlanesGeometry.js\`：不依赖浏览器的纯 JS/Three.js 网格生成器，\`createHeadPlanes()\` 返回分组、面片数量、部件和调试切换接口。
- \`src/experiments/head/headPlanes.js\`：正交摄影机、OrbitControls、九视图同屏（viewport + scissor）、视角与结构开关。
- \`src/experiments/head/headPlanes.css\`：独立桌面与手机布局。
- \`src/main.ts\`：\`?view=head-planes\` 路由。
- \`tests/head-planes.test.ts\`：镜像顶点、完整包围盒、有限顶点属性、分区可用性及三角面统计。

## 第一阶段：形体与构造

| 结构分区 | 方法 |
| --- | --- |
| 颅骨 | 16 扇区，10 层水平截面，顶底封面；轮廓按顶、颞、后脑及下颌逐渐变窄 |
| 眉眼 | 眉弓突起 + 眼窝暗面（被眉弓遮挡），不加入眼球或睫毛 |
| 颧骨 | 每侧独立的楔形多边形面 |
| 下颌颏部 | 下颌平面向颏部收束，强调与侧颅的角度变化 |
| 鼻梁鼻翼 | 中心鼻梁配对镜像，鼻尖、鼻翼及阴影面分开 |
| 双耳 | 耳轮前后两层与周壁，带耳甲和耳屏块，非单片纸面 |
| 颈肩 | 12 扇区截面串联，正面/背面/侧面均有厚度 |

**对称约束**：侧别要素均用相同坐标数据乘以 \`s ∈ {-1,+1}\` 构建。颅骨与颈肩由完整绕轴截面生成。检查测试要求所有几何顶点存在 X=0 镜像匹配。

**建模取舍**：当前是训练用“基础平面”体块搭建，因此面部区域通过独立分片覆盖主颅壳，而不是已经进行焊接的水密动画拓扑。适合观察和继续调整形体，不应直接用作带表情变形的最终游戏头部。

## 观察与下一轮

九个机位按原图排列：左前 3/4、正面、右前 3/4；左后 3/4、背面、右后 3/4；左侧面、俯视、右侧面。

需要优先从四个方向复查：
1. 正面：眉眼暗面是否处于眉弓后侧，下颌与颏部宽度是否接近参考。
2. 左右侧面：鼻尖突出程度、后脑球壳厚度和下巴后收线是否准确。
3. 3/4：颧骨转折、额侧骨平面与耳部厚度是否看起来像一体。
4. 俯视/背面：头颅中线、颞部宽度、耳位和后颈衔接是否合理。

后续若需要捏人或骨骼绑定，再把相邻面统一为共享顶点网格，并围绕眼眶/嘴颌加边循环；不能将当前跨片覆盖误认为已焊接。
