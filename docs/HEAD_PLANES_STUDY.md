# Basic Planes of the Head：正面半边布线 → 镜像 → 深度重建（第二版）

在线页面：[\`?view=head-planes\`](https://giogyan90.github.io/RoomBoy/?view=head-planes)

## 为什么推翻第一版

第一次做法使用 16 扇区近似椭球头壳，并将眉弓、眼窝、鼻梁、颧骨、下颌以独立的多边形覆盖在表面，导致正面没有对应参考的结构线、侧面可见层叠/悬空的三角形、鼻形和颅骨比例都偏离原图。**2026-11-17 已整体废弃这种构造。** 不允许再以“额外贴一块面”补救正面顶点位置。

本页的参考是用户提供的九角度灰色头部平面图（标题 \`BASIC PLANES OF THE HEAD\`，veliscek.com）。我们不声称从图片中自动还原了几何结构，而是按正面/侧面轮廓手工选点。

## V2 的三步实际构建过程

1. **左半正面取点**：\`FRONT_LEFT_HALF_ROWS\` 是唯一人工定位的正面源：12 条高度线，每条六个点，按中心轴到脸部外轮廓排列，总计 **72 个左半脸坐标**。每个点同时有 X、Y、Z，其中 X/Y 负责正面投影，Z 由多角度轮廓手工拟合。编辑端点优先调整这里，勿添加单独悬浮五官网格。
2. **复用中线并镜像**：从左半源数据的 X 取相反数得到右半。两个半脸在一整圈同一套顶点索引上连接，**前中线 X=0 没有重叠的两套中心点**；\`?view=head-planes&stage=mirror\` 可以先检查正面。
3. **侧面赋深度并闭合后脑**：每行的外侧边界向后延伸四个截面点，沿后中线再镜像；接着将同一 18 顶点环连接成侧后脑整体。与下方六层颈肩过渡环一起构成一个完整头、颈、肩、胸底的**单个索引网格**，而非眼/鼻/嘴/下颌附加卡片。顶部、底部各封一圈端面，正面/侧面/背面/俯视均有厚度。

其中耳部用左右对称、封闭的简化耳廓楔体做两个独立附属网格，它们不是贴在额头上的面片；如果未来骨骼绑定，须再焊接耳根、细化耳内环。

## 工程约束与剩余检查

- 每个面部三角形必须和相邻面通过**同一顶点索引**连接，不允许再给眉弓、鼻梁、眼窝补独立大面造成悬浮感。
- 正面以左右镜像为刚性不变量；编辑负 X 端点后正 X 自动镜像。
- 几何测试检查主头部、颈肩网格每一条索引边恰好被两片三角形使用；三角面数量不足以说明视觉还原准确。
- 当前不是最终拓扑。虽然基础共边且封闭，眼角、鼻翼、唇周没有可用于表情绑定的边循环；大形得到确认之前先不要增加不必要细分。
- 视觉待复核：正面眉眼黑色横带、颧骨主转折；侧面的鼻根—鼻尖—下颌角曲线；背面的颅骨圆弧；3/4 角度下是否有突然的凸包/凹角；颈肩比例是否与参考一致。造型的最终贴合度仍需要看网页实际截图，不应被测试成功替代。
