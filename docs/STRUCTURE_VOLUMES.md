# 结构体积修订

本轮仍以彩色几何体块简化三视图为基准；保持第 1 阶段，不启用原始概念图细雕。

## 体积调整

- 颈后：补充枕下与颈根截面，向肩背延伸后侧根部，避免直筒脖颈。
- 臀部：增加后凸截面，在同一闭合网格内形成左右体积和中央浅收口；下缘整体渐变抬升，防止只移动底圈造成相邻面折叠。
- 颅顶：加入顶部弧线截面，减轻尖锥感，保持头顶定位点。
- 足背：使用七层截面区分薄前掌、中足坡面与踝前较陡过渡。
- 二头肌：增加上臂前侧中段体积，并向肩端与肘端收窄。
- 胸肌：在胸腔整体网格上形成左右前侧平面与浅胸骨凹槽，不附加独立球体。

胸腔、骨盆与颅顶局部使用至少 16 个环向顶点，其余部位保持低密度。截面数据与塑形逻辑分别位于 bodyReference.ts、bodyStructure.ts；真实网格构建由 bodyBlockout.ts 负责。

## 自查与验证

检查页新增前斜侧、后斜侧视角，用于观察胸肌、后颈和臀部厚度。二维参考叠合只在对应正交三视图启用。自行载入当前简化图，检查正、侧、背、两个斜侧角度及线框、剪影、并排、定位点；桌面与手机视口未出现脚本错误。

体块版 1,840 三角面，后续密度版本 2,472 三角面。十项测试覆盖原有资产兼容性、真实顶点定位，以及胸骨和胸肌相对深度、双侧臀部体积、后颈延伸、颅顶曲率、足背坡度与骨盆逐圈不折返。生产构建包含 TypeScript 检查。

真实网格定点 RMS：正 0.98、侧 0.39、背 0.94 个源图像素。这只是关节定点误差，不代表整体外形一致。

## 当前边界

模型仍是分块闭合几何体，尚未建立连续焊接、用于变形的全身拓扑。骨盆与大腿交界仍偏硬，肌肉也只是大体积，尚无精细解剖转折。本轮没有推进到五官、衣褶、发丝和原概念图特征。

对照图通过离线工具直接投影真实三角网格生成；参考图与对照图均不进入公开仓库。分享页可由用户本地选择参考图。
