# 实际网格对齐（历史阶段）

此页使用详细概念图的做法已暂停；当前先对齐几何体块简化图，见 [BLOCKOUT_BASELINE.md](BLOCKOUT_BASELINE.md)。

本轮自行将原设定的正、侧、背面放在模型旁边并叠合检查，重新读取头颈、肘腕与膝部位置，再让这些约束影响真实体块截面。

## 修正原来的检查漏洞

上轮绿色标记直接复制目标坐标，不能证明网格本身已经对齐。本轮标记来源改为：

- 头顶：发包顶端封口的实际中心顶点。
- 下巴：头部最低截面的前方实际顶点。
- 颈根、肩、肘、腕、髋、膝、踝：相应体块端面封口的实际中心顶点。

`bodyConstraints.ts` 将目标位置施加到关节截面；相邻上、下肢体块使用同一连接站位。移动腕部约束会移动前臂和手掌的真实端面，不会只移动显示点。测试包含这一反例检查。

## 原图读点与各角度约束

将原图放大，并叠加原始像素网格读点。重新读取下巴、颈根、肘部和膝部，保留三视图独立的可见点：

- 正面约束 X、Y；侧面约束 Z、Y；背面约束 −X、Y。
- 对同一三维关节点做等权最小二乘折中，使用同一模型接受三视图检查，没有为每个角度建立不同的身体。
- 下巴和颈根在背面不可见，不编造背面对应点。
- 手工读取仍有误差；原画的三幅姿势与透视也并非完全一致。因此单个点不能在全部视图里同时达到零误差。

读点与换算位于 `bodyReference.ts`；原图像素没有进入仓库。

## 此轮网格修改

1. 颈根沿侧面位置重新定位；下巴最低截面和高度重新校准。
2. 肩部连接截面、上臂根部、肘部端面、前臂与手掌的连接端面按定点一致连接。
3. 髋、膝、踝使用同一目标坐标控制上下体块的接头，重新调整膝盖高度与侧面轴线。
4. 发包增加一个低面外轮廓环：保留后脑最大体积，另行收窄后颈下缘，修正原来把后脑最宽截面直接拉到颈后的拖尖轮廓。仍不制作发丝。
5. 两种密度使用相同约束，分别为 1,392 / 2,088 三角面。

误差单位是原始 1200 × 800 设定图中的像素。从真实网格顶点投影，比较各视图独立手工读点：

- 自行载入原图，分轮检查正、侧、背面的叠合，以及三组原图/模型并排图；同时查看无参考图遮盖的灰模。
- 绿色点读取实际网格，紫色十字是原图固定点，连接线显示偏差。背面的十字不是正面点的镜像。
- 检查页新增“并排对照”。原图在本地载入；本轮自查已经完成，不以用户重新上传或自行检查作为完成条件。
- 九项自动测试通过：包含原有资产/动作测试、闭合体块、两个密度的截面坐标、改变约束实际移动网格等检查。
- 桌面、移动视口的检查控件、本地文件选择、无效尺寸回退、旧人物入口已验证；没有页面脚本异常。

## 离线检查图

`tools/export-structure-study.ts` 从真实网格三角形导出 SVG 技术对照图，不依赖浏览器截图。调用时传入本地原图和本地输出路径：

```sh
node --import tsx tools/export-structure-study.ts REF.png OUT.svg
```

输出包含输入原图，默认不应提交到公开仓库。本轮对照图单独交付；公开项目只包含导出代码。
